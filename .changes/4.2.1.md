## 4.2.1 - 2026-10-14

### 🪲 Fixed

* [#1113](https://github.com/microsoft/terraform-provider-power-platform/issues/1113) Fix unintended IP firewall updates when configuring product features on non-managed environments
* [#1281](https://github.com/microsoft/terraform-provider-power-platform/issues/1281) Importing or refreshing `powerplatform_environment_group_rule_set` no longer fails with `MaximumShareLimit value not found in response` for groups that have further `Sharing` parameters (for example `AuthoringBot`, created by the "Sharing agents with Editor permissions" rule in the admin center). `sharing_controls` is now read from the `App` sharing parameter only, and a missing `MaximumShareLimit` is read as null.
* [#1248](https://github.com/microsoft/terraform-provider-power-platform/issues/1248) Return the HTTP client error when a redirect policy fails instead of masking it with a response body read error
* [#1247](https://github.com/microsoft/terraform-provider-power-platform/issues/1247) Data sources now enforce the configured `timeouts.read` value
* [#1285](https://github.com/microsoft/terraform-provider-power-platform/issues/1285) `powerplatform_environment_group_rule_set` no longer removes rule set parameters not managed by Terraform (e.g. `Sharing` for `AuthoringBot` set in the admin center) on update or destroy, and adopts an existing rule set on create instead of failing with `RuleSetAlreadyExistsError`
* [#1289](https://github.com/microsoft/terraform-provider-power-platform/issues/1289) Updating `powerplatform_environment` no longer shows untouched attributes (`allow_bing_search`, `allow_microsoft_365_services`, `allow_moving_data_across_regions`, `allow_flex_routing`, `dataverse.templates`, and `dataverse` for environments without Dataverse) as `(known after apply)`.
* [#1246](https://github.com/microsoft/terraform-provider-power-platform/issues/1246) Cap retries of transient HTTP statuses in the shared API client at MAX_RETRY_COUNT and repeated 401 responses at MAX_UNAUTHORIZED_RETRIES so permanent failures surface instead of retrying until the operation timeout
